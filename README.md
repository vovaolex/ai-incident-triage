# AI Incident Triage

A Python-based automation project for processing and triaging IT incidents.

## Current Features

- Load incidents from JSON
- Normalize incident data
- Calculate incident priority
- Send incident data to an external API
- Handle HTTP and network errors
- Use environment variables for secrets

## Tech Stack

- Python
- Requests
- JSON
- Git
- GitHub
